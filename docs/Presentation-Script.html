2. System Demonstration & Core Features (System Functionality — 30%)

[DEMO: Navigate through the Portal]

"Our system provides comprehensive functionality tailored for both Alumni and Administrators:

A. Alumni Portal Highlights:
  • Authentication & Role Access: Dual-role sign-in switch (Alumni vs. Admin) with salted Web Crypto password security and validation feedback.
  • Facebook-Style Alumni Profile: Clean profile featuring verified badges, overlap avatar picture with camera edit triggers, and an Intro box for education, employment, and social links.
  • Contextual Modal Editing: Tabbed profile modal allowing alumni to update Bio Quotes, Personal Details, Social Media Links, and Avatars effortlessly.
  • Career Tracking Timeline: Interactive employment timeline recording job position, company, location, employment status, and private/public salary settings.
  • Alumni Directory & Search: Filterable graduate directory searchable by degree program, batch year, and employment status.
  • News & Activity Feed: Combined stream of official campus announcements and alumni journey updates with endorsement counters.
B. Admin Control Center & Batch Document Vault:
  • Admin Dashboard: Real-time charts for graduate employment distribution, course statistics, and batch counts built with Recharts.
  • Batch Graduate Document Storage & Archive: Dedicated repository enabling admins to upload, store, organize, preview, and download official PDF graduate rosters (.pdf) and Excel masterlists (.xlsx, .xls, .csv) grouped by graduation batch year.
  • Smart Masterlist Parser: Automatically parses graduate masterlists (LAST NAME, FIRST NAME, MID NAME) and imports graduates directly into the directory with celebratory feedback.
  • Manage Announcements & Reports: Tools to publish campus announcements and export CSV reports.
"
