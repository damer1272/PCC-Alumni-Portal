
# PCC Alumni Portal

Alumni Career Tracking and Networking Portal for Pagadian Capitol College, Inc.

The original Figma design source is available at https://www.figma.com/design/EURVJMenJyvIJvPoLhY4Tx/Set-background-image.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
