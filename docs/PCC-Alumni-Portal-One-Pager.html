PCC Alumni Portal

Alumni Career Tracking & Networking Portal · Pagadian Capitol College, Inc.

Version: 0.0.1 (Frontend Prototype)
Stack: React · Vite · Tailwind · React Router
Run: npm install → npm run dev → localhost:5173

Project Summary

A web-based alumni networking and career tracking system with two roles: Alumni (profile, directory, career timeline, announcements) and Admin (dashboard, manage alumni, announcements, reports, users). The UI and navigation are largely complete; backend, database, and real authentication are not yet implemented.

How It Was Built

  • Phase 1: Requirements & Figma design tokens (brand colors, typography)
  • Phase 2: Vite + React setup, routing, Tailwind styling
  • Phase 3: Auth screens (Login, Register, Forgot Password) — UI only
  • Phase 4: MainLayout — creative alumni shell + classic admin sidebar
  • Phase 5: Alumni pages (dashboard, profile, career, directory, news)
  • Phase 6: Admin pages (dashboard, CRUD tables, charts, reports)
  • Phase 7: Mock data in src/app/data.ts
  • Phase 8: UI polish — networking design, profile sketch layout, edit modal, nav fixes

Architecture (Current)

  • Frontend SPA — React Router for all pages
  • Data layer — static mock arrays + page-level useState
  • Auth — simulated login (1.2s delay, no validation)
  • Backend / API / DB — not connected

What Is Working

  • Full routing for alumni & admin modules
  • Role switch (Alumni ↔ Admin) and logout
  • Alumni dashboard, directory search/filter, announcements
  • Creative profile page + edit profile modal (blur overlay)
  • Career form UI + employment timeline display
  • Admin stats, charts (Recharts), announcement CRUD (session only)
  • Responsive layout (desktop nav + mobile bottom bar)
  • Production build: npm run build

What Still Needs Work

  • Real authentication & protected routes
  • Database + REST/API for all CRUD operations
  • Persist profile, career, and admin changes (currently lost on refresh)
  • Profile photo upload & file storage
  • Email flows (register, forgot password)
  • Export PDF/Excel on reports (buttons are UI only)
  • Sync charts with live data; wire admin action buttons
  • Official PCC logo asset; deployment to production hosting
