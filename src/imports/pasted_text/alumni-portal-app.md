# Alumni Career Tracking and Networking Portal — Design Specification

Technology Stack:
- React (Latest)
- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS / Vanilla CSS
- React Router
- Lucide Icons
- Recharts for dashboard charts

Design Requirements:
- Modern University Portal
- Clean and Professional
- Mobile Responsive
- Deep Navy, Warm Amber, & Off-White Theme
- Rounded Cards & Glassmorphism
- Smooth Micro-Animations
- Responsive sidebar and top navigation bar
